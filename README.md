# Trace Brand Building website concept

Responsive static HTML prototype with 20 webpages and a start guide.

## Preview
Open `index.html` locally or serve this directory with a static web server. No build step or dependencies are required.

## GitHub Pages
In repository Settings → Pages, choose **Deploy from a branch**, then **main** and **/ (root)**.

## Scope
Includes the approved right-side homepage animation, team portraits, project gallery and service pages. The contact form prepares an email draft; it does not send or store enquiries. Some case studies, articles and team profiles link to the original website.

This is a review prototype. Pages include noindex metadata. Confirm copy, team roles and production form requirements before launch. Original Trace artwork, photography and brand assets remain the property of their respective owners; no open-source licence is granted for those assets.
